# 🎬 Bidu AI – Bollywood Inspired AI Chatbot

Bidu AI is a fun, Bollywood-inspired AI chatbot built in Python using Google's Gemini API. Unlike traditional chatbots, Bidu AI responds with a unique Bollywood flair, adding humor, iconic dialogues, and entertaining expressions while still providing helpful and intelligent answers.

Whether you're asking a technical question, seeking advice, or just chatting for fun, Bidu AI delivers responses with a cinematic twist.

---

## 🌟 Features

- 🎭 Bollywood-inspired personality
- 🤖 Powered by Google's Gemini AI
- 💬 Interactive conversational interface
- 😂 Funny and engaging responses
- 🧠 Intelligent answers to general and technical questions
- ⚡ Fast response generation

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/PRIYANKA0045/Bidu-AI.git
cd Bidu-AI
```

### Create a Virtual Environment

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux/macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure API Key

Create a `.env` file in the project directory.

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Get your Gemini API key from **Google AI Studio**.

### Run the Application

```bash
streamlit run app.py
```
